## 1. Compare UX Designs

Evaluate different design options to understand the usability. The prompt allows you to compare options and enable decision-making.

Model: Gemini-Pro (Best) 

**Prompt:**

> **Role:** Act as a Senior UX Researcher and Product Designer with expertise in cognitive psychology and human-computer interaction.
> 
> **Task:** Evaluate the following design options for [Insert Feature Name, e.g., The "Set Reminder" Modal] using the specific Cognitive Usability Framework provided below.
> 
> **The Framework Criteria:**
> 
> - **Reduces Decisions:** Does the design present a clear path, or does it force the user to deliberate?
> 
> - **Reduces Memory Load:** Does the user have to remember information from a previous screen, or is the context provided in place?
> 
> - **Uses Recognition > Recall:** Does the design use standard, recognizable patterns (visible affordances), or does it force the user to guess/remember hidden interactions?
> 
> - **Minimises Time on Task:** How many clicks/seconds does it take to solve the problem?
> 
> - **Minimises Errors and Rework:** Does the design prevent the user from making a mistake or hitting a dead end?
> 
> **Context of the Problem:** [Insert a brief description of the user's goal and the current friction point. Example: Users are trying to set a reminder, but the feature is disabled in global settings.]
> 
> **The Design Options:**
> 
> - **Option 1:** [Describe Option 1. Example: A grayed-out toggle that does nothing.]
> 
> - **Option 2:** [Describe Option 2. Example: Removing the toggle and showing a text link.]
> 
> - **Option 3:** [Describe Option 3. Example: A grayed-out toggle that opens a popup when clicked.]
> 
> **Required Output:**
> 
> - **Analysis:** Briefly analyze each option against the 5 criteria.
> 
> - **Comparison Matrix:** Create a table with the Options as columns and the Framework Criteria as rows. Rate each cell as High, Medium, or Low (where "High" indicates a positive UX outcome, e.g., High reduction of memory load).
> 
> - **Recommendation:** Select the winner and explain why it is the superior choice based on the framework.
